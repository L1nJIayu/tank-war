# Tank War (坦克大战)

[English](#english) | [中文](#中文)

---

## English

A classic tank battle web game built with Vue 3 and Vite.

### Features

- 🎮 Arrow keys to move tank
- 🔫 Space to fire bullets
- 🤖 5 enemy tanks with AI
- ❤️ 3 lives system
- 🏆 Score tracking

### Tech Stack

- **Vue 3** - Composition API
- **Vite** - Build tool
- **HTML5 Canvas** - Game rendering

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Controls

| Key | Action |
|-----|--------|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |
| Space | Fire |

## 中文

使用 Vue 3 和 Vite 构建的经典坦克大战网页游戏。

### 游戏特性

- 🎮 方向键控制坦克移动
- 🔫 空格键发射炮弹
- 🤖 5辆敌方坦克 (AI巡逻)
- ❤️ 3条生命值
- 🏆 分数统计

### 技术栈

- **Vue 3** - Composition API
- **Vite** - 构建工具
- **HTML5 Canvas** - 游戏渲染

### 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build

# 预览构建结果

```
